# 🎰 Memetric Casino

Браузерное казино с виртуальной валютой. Все игры работают на чистом HTML/CSS/JavaScript без зависимостей.

## Игры

- **🎰 Слоты** — Крути барабаны и собирай комбинации
- **🎡 Рулетка** — Классическая европейская рулетка с анимированным колесом
- **🃏 Блэкджек** — Обыграй дилера, набрав 21 очко
- **📈 Краш** — Успей забрать до краша множителя
- **💣 Мины** — Открывай ячейки, избегая мин (5×5 поле)
- **🎲 Кости** — Угадай, выпадет больше или меньше числа

## Запуск

Просто откройте `index.html` в браузере. Никаких сборок или зависимостей не требуется.

```bash
# Или с локальным сервером:
npx serve .
```

## Особенности

- Виртуальная валюта (💎), сохраняется в localStorage
- Адаптивный дизайн (мобильная и десктоп версии)
- Тёмная неоновая тема
- Плавные анимации
- Честный RNG (генератор случайных чисел)
