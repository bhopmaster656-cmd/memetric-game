# MEMETRIC

**Rhythm Meme Platformer** – HTML5 игра для Яндекс.Игры 🎮

## Описание

MEMETRIC – это ритм-платформер с мемами. Персонаж автоматически бежит по неоновому
киберпанк-миру. Прыгай в такт музыки, уворачивайся от препятствий, собирай монеты и
бей рекорды в таблице лидеров!

## Геймплей

- **Нажми/тап** (пробел, стрелка вверх, клик/тап) – прыжок
- **Двойной прыжок** – ещё раз до приземления
- Скорость нарастает со временем
- Монеты тратятся в магазине на скины

## Монетизация (Яндекс.Игры)

| Тип | Описание |
|-----|----------|
| **Interstitial Ads** | Показывается после завершения раунда |
| **Rewarded Video** | Просмотр рекламы → возрождение с 1 жизнью |
| **In-App Purchases** | Пакеты монет (15–249 ₽) |
| **Магазин скинов** | Покупка скинов за внутриигровые монеты |
| **Таблица лидеров** | Яндекс Leaderboards API |

## Структура файлов

```
index.html      – основной HTML-файл (точка входа)
style.css       – стили (загрузочный экран, меню, UI)
game.js         – игровая логика (Canvas 2D, физика, YaGames SDK)
manifest.json   – манифест для Яндекс.Игр (IAP, leaderboards)
icon-512.svg    – иконка 512×512 для публикации
```

## Публикация в Яндекс.Игры

1. Создай аккаунт разработчика на [yandex.ru/games/develop](https://yandex.ru/games/develop)
2. Создай новую игру, выбери «HTML5»
3. Загрузи все файлы в архив **ZIP**:
   - `index.html`, `style.css`, `game.js`, `manifest.json`, `icon-512.svg`
4. В настройках игры добавь товары IAP (id из `manifest.json`)
5. Создай таблицу лидеров с именем `main_leaderboard`
6. Пройди модерацию и публикуй!

## Технологии

- **Canvas 2D** – рендеринг (без сторонних зависимостей)
- **Yandex Games SDK v2** – авторизация, платежи, таблица лидеров, реклама
- **LocalStorage** – оффлайн-сохранение прогресса
