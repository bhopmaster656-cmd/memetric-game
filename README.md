# memetric-game

A Unity-based game project.

## Quick Setup

### Prerequisites

- [Unity Hub](https://unity.com/download) with a compatible Unity Editor version installed
- Git

### Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/bhopmaster656-cmd/memetric-game.git
   ```
2. Open Unity Hub and click **Add** → **Add project from disk**, then select the cloned folder.
3. Unity will import all assets automatically. This may take a few minutes on first open.
4. Once the project loads, open the main scene from the `Assets/Scenes` folder and press **Play** to run the game in the editor.
